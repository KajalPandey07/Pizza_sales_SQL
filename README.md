# 🍕 Pizza Sales Data Analysis using SQL

## 📊 Project Overview
This project focuses on analyzing pizza sales data using **MySQL Workbench** to uncover key business metrics, ordering patterns, customer preferences, and revenue drivers.

---

## 🛠️ Tech Stack & Concepts Used
* **Database:** MySQL
* **Tools:** MySQL Workbench, Canva (Presentation)
* **SQL Concepts:** Aggregate Functions (`SUM`, `COUNT`, `AVG`), `GROUP BY`, `ORDER BY`, `JOINS`, Subqueries, and CTEs.

---

## 🔍 Key Business Questions Solved
1. **Total Revenue & Order Metrics:** Calculated total sales revenue, average order value, and total pizza quantity sold.
2. **Sales Trends:** Analyzed peak ordering hours and busiest days of the week.
3. **Category Analysis:** Evaluated revenue share by pizza category (Classic, Supreme, Chicken, Veggie) and sizes (S, M, L, XL).
4. **Performance Ranking:** Identified top 5 best-selling and bottom 5 least-selling pizzas.

---

## 📁 Repository Structure
* `Pizza_Sales_Queries.sql` - Contains all SQL queries solved step-by-step.
* `Pizza_Sales_Data.csv` - Raw dataset used for analysis.
* `Pizza_Sales_Presentation.pdf` - Visual summary and presentation slides.
